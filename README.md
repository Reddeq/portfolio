# REDDEQ // NEXUS

NEXUS OS v0.2 — полноэкранное портфолио в фиолетовой киберпанк-эстетике: DTP, автоматизация и личные проекты.

## Запуск
```sh
python -m http.server 8000
```
Откройте http://localhost:8000. Можно также открыть index.html напрямую. Сборка и сторонние зависимости не требуются.

## Структура
- index.html — все разделы и карточки кейсов, доступные без JavaScript.
- styles.css — оболочка консоли, адаптивная сетка, перспективный фон, 400 мс glitch/decode, Netrunner-режим, reduced motion.
- app.js — переключение модулей, hash-навигация, журнал команд и сохранение режима.
- assets/nexus.svg — собственный знак сайта.

## Терминал
help, whoami, ls, dtp, dev, lab, contact, home, clear. Секретная команда: manul. Это локальная навигация, не оболочка операционной системы. Режим Netrunner включён по умолчанию для новых посетителей, отключается кнопкой; прежняя настройка сохраняется. При reduced motion переключение мгновенное.

## Ручная проверка
Откройте сайт на широком и узком экране, пройдите по всем ссылкам навигации, проверьте Back/Forward, прямую ссылку #apo100, быстрые переключения модулей и отсутствие прокрутки внешней оболочки, раскройте карточки, выполните команды help, dtp, dev, lab, contact, clear, manul. Переключите Netrunner и перезагрузите страницу. Проверьте reduced motion и работу без JS.
