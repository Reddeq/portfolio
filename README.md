# REDDEQ // NEXUS

Первая версия личного портфолио в фиолетовой киберпанк-эстетике: DTP, автоматизация и личные проекты.

## Запуск
```sh
python -m http.server 8000
```
Откройте http://localhost:8000. Можно также открыть index.html напрямую. Сборка и сторонние зависимости не требуются.

## Структура
- index.html — все разделы и карточки кейсов, доступные без JavaScript.
- styles.css — дизайн, адаптивная сетка, перспективный фон, Netrunner-режим, reduced motion.
- app.js — терминал и сохранение режима.
- assets/nexus.svg — собственный знак сайта.

## Терминал
help, whoami, ls, dtp, dev, lab, contact, home, clear. Секретная команда: manul. Это локальная навигация, не оболочка операционной системы. Режим Netrunner включается вручную и не обязателен.

## GitHub Pages
Репозиторий сейчас приватный. На GitHub Free публикация Pages требует публичного репозитория. Не меняйте видимость, пока не проверены материалы и история Git. После проверки: Settings → Pages → Deploy from a branch → main / (root). Адрес project site: https://reddeq.github.io/portfolio/. Все локальные ссылки относительные.

Откройте сайт на широком и узком экране, пройдите по всем ссылкам навигации, раскройте карточки, выполните команды help, dtp, dev, lab, contact, clear, manul. Переключите Netrunner и перезагрузите страницу. Проверьте reduced motion и работу без JS.
