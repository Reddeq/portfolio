# REDDEQ // NEXUS OS v0.3

Два независимых статических портфолио с общей полноэкранной консолью.

## Запуск
```sh
python -m http.server 8000
```
- http://localhost:8000/ — шлюз выбора специализации
- http://localhost:8000/dtp/ — DTP Archive: HOME, WORKS, SKILLS, CONTACT
- http://localhost:8000/automation/ — Toolchain: HOME, PROJECTS, STACK, LABORATORY, CONTACT

Без сборки и зависимостей. index.html, dtp/index.html и automation/index.html — независимые HTML-страницы с собственными метаданными. styles.css и app.js общие. Ссылки относительные, подходят для project site GitHub Pages.

## Навигация
Внутри каждого пространства используется hash-навигация. Например /dtp/#apo100 и /automation/#pdfconverter открывают карточки кейсов. Старые ссылки /#apo100 и /#pdfconverter перенаправляются в соответствующие пространства при включённом JS. Через NEXUS можно сменить специализацию. Команды help и ls показывают доступные модули; dtp/dev/nexus переключают пространства (nexus — из специализированных страниц). Визуальные эффекты включены по умолчанию; при reduced motion анимации отключены. Без JS все материалы доступны на соответствующей странице с обычной прокруткой.

## Фоновая музыка
На всех трёх страницах `SOUND ON / OFF` управляет зацикленным треком. По умолчанию звук выключен. Если браузер блокирует возобновление при переходе на другую страницу, нажмите кнопку снова.

«Electric Dreams» — Scott Buckley, [страница трека](https://www.scottbuckley.com.au/library/electric-dreams/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). MP3 хранится в `assets/audio/`.

Публикация и видимость репозитория не менялись.

## Материалы
В `assets/dtp/` хранятся только растровые WebP-превью выбранных страниц и разворотов. Полные выпуски, исходные документы, рабочие файлы, промежуточные экспорты и персональные данные не должны попадать в структуру сайта или историю Git. Рендер и обезличивание выполнять вне репозитория; перед публикацией проверить превью и согласование показа.

## Проверка
Проверить все три URL, перезагрузку прямых ссылок, Back/Forward, быстрые переключения, включение и выключение звука, reduced motion, клавиатуру, мобильный экран и отсутствие JS. DTP не должен содержать личных проектов и инструментов автоматизации.
