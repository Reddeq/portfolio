# REDDEQ // NEXUS

Статическое портфолио: DTP, автоматизация и личные проекты.

## Запуск

В корне репозитория: `python -m http.server 8000`, затем http://localhost:8000. Сборка и зависимости не требуются.

## Публикация

Для GitHub Pages на бесплатном тарифе потребуется публичный репозиторий. После проверки содержимого: Settings → Pages → Deploy from a branch → main / (root). Адрес проекта: https://reddeq.github.io/portfolio/.

Не публикуйте оригинальные клиентские документы, персональные данные, исходные PPTX и необезличенные PDF. Добавляйте только согласованные, необратимо обезличенные превью в assets/.
